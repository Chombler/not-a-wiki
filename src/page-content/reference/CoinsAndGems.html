Coins are the main currency within an Era. Gems are the persistent production resource earned by abdicating.

Coin currencies

The name of the main coin currency changes with each Ascension. The currency change does not alter its basic role: it is produced and spent during the current Era.

Coins

Buildings, assistants, clicks, spells and upgrades can produce coins. Coins buy buildings, upgrades and other progression purchases. Abdication resets the current coin total together with buildings and ordinary upgrades.

Gems

Abdication awards additional Gems based on the coins produced. Owned Gems increase production and are kept through later Abdications, allowing each Era to begin with a larger production bonus.

In every Ascension, n Gems represent 5e11 * n * (n + 1) Coins. The game compares the coins represented by the prospective total with those represented by the Gems already owned to determine the gain available from Abdication.

Coin and Gem appearance

Currency icons

The main currency icon changes with Ascension. Gems retain the same icon across Ascensions.

Selectable coin particles

Completing the required feats during some events permanently unlocks these alternate coin-particle shapes. The selected particle is cosmetic and does not affect Coins or Gems.
