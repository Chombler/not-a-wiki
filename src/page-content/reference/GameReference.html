This section defines the conventions used to express Realm Grinder values and formulas throughout the wiki.

Displayed values

Unless a page explicitly describes an internal tick value, rates are written in the units displayed by the game. Mana Regeneration is therefore expressed as mana per second. When source formulas use a value multiplied by 30 because the internal value is mana per tick, the wiki presents the equivalent per-second quantity.

Formula conventions

  • Variables are defined immediately after the formula that uses them.
  • Time units are stated explicitly.
  • Additive and multiplicative effects are identified when that distinction affects stacking.
  • Displayed rounding and random-chance behavior are distinguished from underlying calculations when known.

See Notation for number formats, Terminology for game vocabulary, and Random Number Generation for chance-based mechanics.
